# Review UI (AI document filing, slice 2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the PWA's home screen with an inbox where the user reviews, approves, edits and discards the documents the server has analysed, sees what is in progress, failed, filed or discarded, and edits the filing settings.

**Architecture:** The server already exposes everything except a Drive link for filed documents. Tasks 1–2 add the link: migration 006 adds `drive_url`, filled best-effort after filing. The PWA gains a `documents/` module: typed API client, a polling `DocumentSync` store, and pure grouping and folder-search functions. It also gains `ui/inbox/` components (inbox, review card, folder picker, rows) and a settings screen. `App.tsx` makes the inbox the home route. The scanner and saved scans stay as they are; slice 4 reworks them.

**Tech Stack:** Preact 10 with hooks, TypeScript (strict, `exactOptionalPropertyTypes`, `noUncheckedIndexedAccess`), Vite, Vitest with happy-dom and `@testing-library/preact`, Hono and `node:sqlite` on the server.

**Spec:** `docs/superpowers/specs/2026-10-09-ai-document-filing-design.md`, §5 "Review and activity (PWA)" and the slice-2 entry under "Delivery slices".

## Scope decisions (user, 2026-10-10)

- **No Add screen in this slice.** The spec keeps the file picker, drag-and-drop and offline queue in slice 4. Until then, documents arrive through the API (`POST /api/documents`).
- **No preview of the original.** Thumbnails come with slice 3. The review card shows the original filename, the suggested name and folder, the confidence, the review reason and the model's rationale.
- **Drive links are stored at filing.** Migration 006 adds a plaintext `drive_url` column. It holds only IDs, like `drive_node_uid`. Documents filed before this lands have no link.
- **Home screen.** The inbox replaces `StatusScreen`. Theme and sign-out move to the settings screen. **Scan** stays on the inbox header, and **Saved scans** moves to the inbox footer until slice 4 reworks the scanner.

## Conventions for every task

- **Node:** `export PATH="$HOME/.local/share/fnm/node-versions/v$(cat .nvmrc | tr -d v)/installation/bin:$PATH"` from the repo root before any `pnpm`. `fnm use` alone is not enough; vitest workers pick up the wrong Node.
- **Server tests:** `cd server && pnpm test`. For one file: `cd server && NODE_OPTIONS=--import=tsx pnpm exec vitest run <file>`. Typecheck: `pnpm --filter @doc-scanner/server run typecheck`.
- **PWA tests:** `cd pwa && pnpm exec vitest run <file>` (no loader needed); the full run is `pnpm --filter @doc-scanner/pwa test`. Typecheck: `pnpm --filter @doc-scanner/pwa run typecheck`.
- **Strict TS:** `exactOptionalPropertyTypes` is on. Don't pass `undefined` to an optional prop; spread it conditionally (see `App.tsx`'s `resumeScanId`). `noUncheckedIndexedAccess` makes indexed reads `T | undefined`.
- **Tests and teardown:** the PWA suite has a known teardown race: a late `setState` after a test ends shows up as "document is not defined". Every UI test must `await` the final state it caused (`waitFor`/`findBy…`) before it ends. `tests/setup.ts` already runs `cleanup` after each test.
- **Public repo:** fictional data only, such as "Northwind Energy" and `/Bills/Energy`. No real names, paths or document text in code, tests or commits.
- **Commits:** Conventional Commits, one per task unless a step says otherwise, signed automatically. `git add` only the task's files.

```ts
import type { ApproveBody, DocumentView, FolderEntry, Settings } from './types.js';

const doc = (id: string, action: string) => `/api/documents/${encodeURIComponent(id)}${action}`;

export const documentsApi = {
  list: (since: number) => request<{ documents: DocumentView[]; cursor: number }>(`/api/documents?since=${since}`),
  get: (id: string) => request<DocumentView>(doc(id, '')),
  approve: (id: string, body: ApproveBody) =>

  retry: (id: string) => request<DocumentView>(doc(id, '/retry'), { method: 'POST' }),
  folders: () => request<{ walkedAt: string; folders: FolderEntry[] }>('/api/folders'),
  refreshFolders: () => request<{ ok: true }>('/api/folders/refresh', { method: 'POST' }),
  settings: () => request<Settings>('/api/settings'),
  saveSettings: (patch: Partial<Settings>) =>
    request<Settings>('/api/settings', { method: 'PUT', body: JSON.stringify(patch) }),
};

export type DocumentsApi = typeof documentsApi;
```

## Task 4: `DocumentSync` (polling store)

**Files:**
- Create: `pwa/src/documents/sync.ts`
- Test: `pwa/tests/documents/sync.test.ts`

The server has a change feed: `GET /api/documents?since=<cursor>` returns rows changed after the cursor, oldest first, in pages of up to 500, plus the next cursor. The store keeps every document by id and pulls pages until one comes back empty. It polls every few seconds while the page is visible, and right away when it becomes visible again. A version is kept only if its `seq` is at least the one already held, so a slow poll can't overwrite a newer row that an action response has already supplied.

```ts
import { useEffect, useState } from 'preact/hooks';
import { ApiError } from '../api.js';
import type { DocumentView } from './types.js';

type ListFn = (since: number) => Promise<{ documents: DocumentView[]; cursor: number }>;

export interface DocumentSyncOptions {
  list: ListFn;
  intervalMs?: number;
  /** The session is gone: polling stops and the app should show the login screen. */
  onUnauthorized?: () => void;
}

/** A guard against a feed that never runs dry within one poll. */
const MAX_PAGES = 20;

/**
 * Every document the server knows about, kept current from the change feed
 * (GET /api/documents?since=<cursor>). One poll pulls pages until one is
 * empty. Polls run every few seconds while the page is visible, and at once
 * when it becomes visible again.
 */
export class DocumentSync {
  private readonly docs = new Map<string, DocumentView>();
  private readonly listeners = new Set<() => void>();
  private cursor = 0;
  private inflight: Promise<void> | null = null;
  private timer: ReturnType<typeof setTimeout> | null = null;
  private running = false;
  /** Bumped by reset(): a poll from before a reset must not put old documents back. */
  private generation = 0;
  /** Bumped by start(): a tick from before a stop/start must not start a second timer loop. */
  private loop = 0;
  error: unknown = null;
  loaded = false;

  constructor(private readonly o: DocumentSyncOptions) {}

  all(): DocumentView[] {
    return [...this.docs.values()];
  }

  subscribe(fn: () => void): () => void {
    this.listeners.add(fn);
    return () => {
      this.listeners.delete(fn);
    };
  }

  /** Takes a document from an action's response, unless a newer version is already held. */
  upsert(doc: DocumentView): void {
    if (this.put(doc)) this.emit();
  }

  poll(): Promise<void> {
    if (!this.inflight) {
      const p: Promise<void> = this.pull().finally(() => {
        // Only its own: reset() may have replaced it with a newer poll since.
        if (this.inflight === p) this.inflight = null;
      });
      this.inflight = p;
    }
    return this.inflight;
  }

  start(): void {
    if (this.running) return;
    this.running = true;
    this.loop++;
    document.addEventListener('visibilitychange', this.onVisibility);
    this.tick();
  }

  stop(): void {
    this.running = false;
    document.removeEventListener('visibilitychange', this.onVisibility);
    if (this.timer !== null) clearTimeout(this.timer);
    this.timer = null;
  }

  /** Forgets everything, for sign-out. */
  reset(): void {
    this.generation++;
    this.inflight = null;
    this.docs.clear();
    this.cursor = 0;
    this.error = null;
    this.loaded = false;
    this.emit();
  }

  private put(doc: DocumentView): boolean {
    const held = this.docs.get(doc.id);
    if (held && held.seq > doc.seq) return false;
    this.docs.set(doc.id, doc);
    return true;
  }

  private async pull(): Promise<void> {
    const generation = this.generation;
    try {
      for (let page = 0; page < MAX_PAGES; page++) {
        const { documents, cursor } = await this.o.list(this.cursor);
        if (generation !== this.generation) return;
        for (const d of documents) this.put(d);
        this.cursor = Math.max(this.cursor, cursor);
        if (documents.length === 0) break;
      }
      this.error = null;
    } catch (err) {
      if (generation !== this.generation) return;
      this.error = err;
      if (err instanceof ApiError && err.status === 401) {
        this.stop();
        this.o.onUnauthorized?.();
      }
    }
    this.loaded = true;
    this.emit();
  }

  private readonly tick = (): void => {
    if (!this.running) return;
    const loop = this.loop;
    const due = document.visibilityState === 'hidden' ? Promise.resolve() : this.poll();
    void due.finally(() => {
      if (this.running && loop === this.loop) this.timer = setTimeout(this.tick, this.o.intervalMs ?? 4000);
    });
  };

  private readonly onVisibility = (): void => {
    if (document.visibilityState === 'visible') void this.poll();
  };

  private emit(): void {
    for (const fn of this.listeners) fn();
  }
}

/** Re-renders on every change in the sync and returns its current state. */
export function useDocuments(sync: DocumentSync): { docs: DocumentView[]; loaded: boolean; error: unknown } {
  const [, setVersion] = useState(0);
  useEffect(() => {
    const off = sync.subscribe(() => setVersion((v) => v + 1));
    // Catch a change that landed between the first render and subscribing.
    setVersion((v) => v + 1);
    return off;
  }, [sync]);
  return { docs: sync.all(), loaded: sync.loaded, error: sync.error };
}
```

```ts
import type { DocumentState, DocumentView } from './types.js';

export const RECENT_FILED_LIMIT = 30;
/** The server purges discarded documents after this long (worker.ts DISCARD_RETENTION_MS). */
export const DISCARD_RETENTION_MS = 7 * 86_400_000;

const WAITING: ReadonlySet<DocumentState> = new Set(['received', 'analyzing', 'preparing', 'ready', 'filing', 'awaiting_login']);

export interface InboxGroups {
  review: DocumentView[];
  waiting: DocumentView[];
  awaitingLogin: number;
  filed: DocumentView[];
  failed: DocumentView[];
  discarded: DocumentView[];
}

const time = (iso: string | null) => (iso ? Date.parse(iso) : 0);
const oldestFirst = (a: DocumentView, b: DocumentView) => time(a.createdAt) - time(b.createdAt);
const newestFirst = (a: DocumentView, b: DocumentView) => time(b.updatedAt) - time(a.updatedAt);

export function groupDocuments(docs: readonly DocumentView[], now: Date): InboxGroups {
  const of = (state: DocumentState) => docs.filter((d) => d.state === state);
  const waiting = docs.filter((d) => WAITING.has(d.state)).sort(oldestFirst);
  return {
    review: of('needs_review').sort(oldestFirst),
    waiting,
    awaitingLogin: waiting.filter((d) => d.state === 'awaiting_login').length,
    filed: of('filed').sort(newestFirst).slice(0, RECENT_FILED_LIMIT),
    failed: of('failed').sort(newestFirst),
    discarded: of('discarded')
      .filter((d) => now.getTime() - time(d.discardedAt) < DISCARD_RETENTION_MS)
      .sort((a, b) => time(b.discardedAt) - time(a.discardedAt)),
  };
}
```

```ts
import type { FolderEntry } from './types.js';

const fold = (s: string) => s.normalize('NFC').toLowerCase();
const byPath = (a: FolderEntry, b: FolderEntry) => a.path.localeCompare(b.path);

/**
 * The folder picker's search: every word of the query must appear somewhere
 * in the path. Folders whose own name (the last segment) has every word rank
 * first, then shorter paths, then alphabetically.
 */
export function searchFolders(folders: readonly FolderEntry[], query: string, limit = 50): FolderEntry[] {
  const words = fold(query).split(/[\s/]+/).filter(Boolean);
  if (words.length === 0) return [...folders].sort(byPath).slice(0, limit);
  const scored: { f: FolderEntry; score: number }[] = [];
  for (const f of folders) {
    const path = fold(f.path);
    if (!words.every((w) => path.includes(w))) continue;
    const own = path.slice(path.lastIndexOf('/') + 1);
    scored.push({ f, score: (words.every((w) => own.includes(w)) ? 0 : 10_000) + path.length });
  }
  return scored
    .sort((a, b) => a.score - b.score || byPath(a.f, b.f))
    .slice(0, limit)
    .map((s) => s.f);
}
```

```ts
import { useCallback, useEffect, useState } from 'preact/hooks';
import { ApiError } from '../api.js';
import type { DocumentsApi } from './api.js';
import type { FolderEntry } from './types.js';

export interface FoldersState {
  folders: FolderEntry[] | null;
  error: string | null;
  busy: boolean;
  reload: () => Promise<void>;
  refresh: () => Promise<void>;
}

/** The folder list (never-file-here folders already left out by the server). */
export function useFolders(api: Pick<DocumentsApi, 'folders' | 'refreshFolders'>): FoldersState {
  const [folders, setFolders] = useState<FolderEntry[] | null>(null);
  const [error, setError] = useState<string | null>(null);
  const [busy, setBusy] = useState(false);

  const reload = useCallback(async () => {
    try {
      setFolders((await api.folders()).folders);
      setError(null);
    } catch (err) {
      setError(
        err instanceof ApiError && err.code === 'folders_not_loaded'
          ? 'The folder list has not loaded from Drive yet.'
          : 'Could not load the folder list.',
      );
    }
  }, [api]);

  const refresh = useCallback(async () => {
    setBusy(true);
    try {
      await api.refreshFolders();
      await reload();
    } catch (err) {
      setError(
        err instanceof ApiError && err.code === 'not_logged_in'
          ? 'Sign in again to read your Drive folders.'
          : 'Could not refresh the folder list from Drive.',
      );
    } finally {
      setBusy(false);
    }
  }, [api, reload]);

  useEffect(() => {
    void reload();
  }, [reload]);

  return { folders, error, busy, reload, refresh };
}
```

```tsx
import { useEffect, useRef, useState } from 'preact/hooks';
import { ApiError } from '../../api.js';
import type { ApproveBody, DocumentView, FolderRef } from '../../documents/types.js';
import type { FoldersState } from '../../documents/use-folders.js';
import { FolderPicker } from './FolderPicker.js';
import { SOURCE_LABEL, confirmDiscard, folderLabel } from './labels.js';

export interface ReviewCardProps {
  doc: DocumentView;
  folders: FoldersState;
  onApprove: (body: ApproveBody) => Promise<void>;
  onDiscard: () => Promise<void>;
}

const APPROVE_ERRORS: Record<string, string> = {
  unknown_folder: 'That folder no longer exists in Drive. Pick another.',
  folders_not_loaded: 'The folder list has not loaded from Drive yet. Try again in a moment.',
  name_required: 'Give the document a name.',
  folder_required: 'Pick a folder.',
  not_in_review: 'This document has already moved on.',
  conflict: 'This document has already moved on.',
};

function sameFolder(a: FolderRef | null, b: FolderRef | null): boolean {
  if (!a || !b) return a === b;
  if (a.kind === 'existing') return b.kind === 'existing' && a.linkId === b.linkId;
  return b.kind === 'new' && a.parentLinkId === b.parentLinkId && a.name === b.name;
}

function bodyFolder(f: FolderRef): NonNullable<ApproveBody['folder']> {
  return f.kind === 'existing' ? { kind: 'existing', linkId: f.linkId } : { kind: 'new', parentLinkId: f.parentLinkId, name: f.name };
}

export function ReviewCard({ doc, folders, onApprove, onDiscard }: ReviewCardProps) {
  const suggested = doc.analysis;
  const [name, setName] = useState(suggested?.name ?? '');
  const [folder, setFolder] = useState<FolderRef | null>(suggested?.folder ?? null);
  const [picking, setPicking] = useState(false);
  const [busy, setBusy] = useState(false);
  const [error, setError] = useState<string | null>(null);
  const changeRef = useRef<HTMLButtonElement>(null);
  const wasPicking = useRef(false);

  // Hand focus back to Change when the picker closes, not to <body>.
  useEffect(() => {
    if (wasPicking.current && !picking) changeRef.current?.focus();
    wasPicking.current = picking;
  }, [picking]);

  async function approve() {
    if (!folder || !name.trim()) return;
    // Only what changed: the server files omitted fields as suggested.
    const body: ApproveBody = {};
    if (name.trim() !== suggested?.name) body.name = name.trim();
    if (!sameFolder(folder, suggested?.folder ?? null)) body.folder = bodyFolder(folder);
    setBusy(true);
    setError(null);
    try {
      await onApprove(body);
    } catch (err) {
      setError((err instanceof ApiError && err.code && APPROVE_ERRORS[err.code]) || 'Could not approve. Try again.');
    } finally {
      setBusy(false);
    }
  }

  async function discard() {
    if (!confirmDiscard(doc)) return;
    setBusy(true);
    setError(null);
    try {
      await onDiscard();
    } catch {
      setError('Could not discard. Try again.');
    } finally {
      setBusy(false);
    }
  }

  return (
    <article class="card review-card" aria-label={`Review ${suggested?.name ?? doc.originalName ?? 'document'}`}>
      <p class="muted">
        {doc.originalName ?? 'Untitled'} · {SOURCE_LABEL[doc.source]}
      </p>
      <label class="field">
        <span class="field-label">Name</span>
        <input value={name} onInput={(e) => setName((e.target as HTMLInputElement).value)} />
      </label>
      <div class="field">
        <span class="field-label">Folder</span>
        {picking ? (
          <FolderPicker
            folders={folders}
            allowNew
            onChoose={(f) => {
              setFolder(f);
              setPicking(false);
            }}
            onCancel={() => setPicking(false)}
          />
        ) : (
          <div class="folder-row">
            {folder ? <span>{folderLabel(folder)}</span> : <em class="muted">No folder suggested</em>}
            {folder?.kind === 'new' && <span class="badge">New folder</span>}
            <button ref={changeRef} class="btn btn-secondary btn-small" disabled={busy} onClick={() => setPicking(true)}>
              Change
            </button>
          </div>
        )}
      </div>
      {suggested && (
        <p class="muted">
          {Math.round(suggested.confidence * 100)}% confident{doc.reviewReason ? ` · ${doc.reviewReason}` : ''}
        </p>
      )}
      {suggested?.rationale && <p class="rationale">{suggested.rationale}</p>}
      {suggested?.contentSeen === false && <p class="muted">Analysed from the file's details only; its contents could not be read.</p>}
      {error && (
        <p class="error-text" role="alert">
          {error}
        </p>
      )}
      <div class="actions">
        <button class="btn" disabled={busy || !name.trim() || !folder} onClick={() => void approve()}>
          Approve
        </button>
        <button class="btn btn-secondary" disabled={busy} onClick={() => void discard()}>
          Discard
        </button>
      </div>
    </article>
  );
}
```

```tsx
      <h2 id={`h-${id}`}>{title}</h2>

  documents = documentsApi,
  now = () => new Date(),
  onScan,
  onSavedScans,
  onSettings,
  onSignInAgain,

  const folders = useFolders(documents);

    } catch {
      void sync.poll();
    }

  const confirmedDiscard = async (d: DocumentView) => {
    if (confirmDiscard(d)) await discard(d.id);
  };
  const restore = async (id: string) => sync.upsert(await documents.restore(id));
  const retry = async (id: string) => sync.upsert(await documents.retry(id));

        <h1>Inbox</h1>

          <p class="muted">Loading…</p>
        ) : g.review.length === 0 ? (
          <p class="muted">Nothing to review.</p>
        ) : (
          g.review.map((d) => (
```

```tsx
import { useEffect, useState } from 'preact/hooks';
import { api, ApiError } from '../api.js';
import { documentsApi, type DocumentsApi } from '../documents/api.js';
import type { Settings } from '../documents/types.js';
import { useFolders } from '../documents/use-folders.js';
import { useTheme } from '../theme/use-theme.js';
import { FolderPicker } from './inbox/FolderPicker.js';

export interface SettingsScreenProps {
  email: string;
  documents?: DocumentsApi;
  onBack: () => void;
  onLoggedOut: () => void;
}

/**
 * The fields that differ from what is saved. The server stores every key it
 * is sent, and a stored value overrides its env default for good, so an
 * untouched field must not be sent: it keeps following its env var.
 */
function changedFields(draft: Settings, saved: Settings): Partial<Settings> {
  const patch: Record<string, unknown> = {};
  for (const key of Object.keys(draft) as (keyof Settings)[]) {
    if (JSON.stringify(draft[key]) !== JSON.stringify(saved[key])) patch[key] = draft[key];
  }
  return patch as Partial<Settings>;
}

export function SettingsScreen({ email, documents = documentsApi, onBack, onLoggedOut }: SettingsScreenProps) {
  const { pref, setPref } = useTheme();
  const folders = useFolders(documents);
  const [saved, setSaved] = useState<Settings | null>(null);
  const [draft, setDraft] = useState<Settings | null>(null);
  const [status, setStatus] = useState<string | null>(null);
  const [picking, setPicking] = useState(false);
  const [busy, setBusy] = useState(false);
  const [refreshed, setRefreshed] = useState(false);

  useEffect(() => {
    documents
      .settings()
      .then((s) => {
        setSaved(s);
        setDraft(s);
      })
      .catch(() => setStatus('Could not load settings.'));
  }, [documents]);

  const set = <K extends keyof Settings>(key: K, value: Settings[K]) => setDraft((d) => (d ? { ...d, [key]: value } : d));
  const patch = draft && saved ? changedFields(draft, saved) : {};
  const dirty = Object.keys(patch).length > 0;

  async function save() {
    if (!dirty) return;
    setBusy(true);
    setStatus(null);
    try {
      const s = await documents.saveSettings(patch);
      setSaved(s);
      setDraft(s);
      setStatus('Saved.');
    } catch (err) {
      setStatus(
        err instanceof ApiError && err.code === 'invalid_input'
          ? 'A value was rejected. The threshold must be between 0.5 and 1, with at most two decimals.'
          : 'Could not save settings.',
      );
    } finally {
      setBusy(false);
    }
  }

  async function refreshFolders() {
    setRefreshed(false);
    await folders.refresh();
    setRefreshed(true);
  }

  async function logout() {
    // Signed out locally either way: a failed request leaves at worst a
    // server session that expires on its own.
    await api.logout().catch(() => {});
    onLoggedOut();
  }

  return (
    <main class="inbox">
      <header class="inbox-header">
        <button class="btn btn-secondary" onClick={onBack}>
          ← Back
        </button>
        <h1>Settings</h1>
      </header>

      <h2>Filing</h2>
      {draft === null ? (
        <p class="muted">{status ?? 'Loading…'}</p>
      ) : (
        <div class="card">
          <label class="field">
            <input type="checkbox" checked={draft.autoFileEnabled} onChange={(e) => set('autoFileEnabled', (e.target as HTMLInputElement).checked)} />{' '}
            File automatically when confident
          </label>
          <label class="field">
            <span class="field-label">Auto-file threshold (0.5 to 1)</span>
            <input
              type="number"
              min="0.5"
              max="1"
              step="0.05"
              value={draft.autoFileThreshold}
              onInput={(e) => set('autoFileThreshold', Number((e.target as HTMLInputElement).value))}
            />
          </label>
          <label class="field">
            <span class="field-label">Model</span>
            <input value={draft.model} onInput={(e) => set('model', (e.target as HTMLInputElement).value)} />
          </label>
          <label class="field">
            <span class="field-label">Effort</span>
            <select value={draft.effort} onChange={(e) => set('effort', (e.target as HTMLSelectElement).value as Settings['effort'])}>
              <option value="low">Low</option>
              <option value="medium">Medium</option>
              <option value="high">High</option>
            </select>
          </label>
          <div class="field">
            <span class="field-label">Never file here</span>
            {draft.excludePaths.length === 0 && <p class="muted">No folders excluded.</p>}
            <ul class="doc-list">
              {draft.excludePaths.map((p) => (
                <li key={p} class="doc-row">
                  <span class="doc-main">{p}</span>
                  <button
                    class="btn btn-secondary btn-small"
                    aria-label={`Remove ${p}`}
                    onClick={() => set('excludePaths', draft.excludePaths.filter((x) => x !== p))}
                  >
                    Remove
                  </button>
                </li>
              ))}
            </ul>
            {picking ? (
              <FolderPicker
                folders={folders}
                allowNew={false}
                onChoose={(f) => {
                  if (f.kind === 'existing' && !draft.excludePaths.includes(f.path)) set('excludePaths', [...draft.excludePaths, f.path]);
                  setPicking(false);
                }}
                onCancel={() => setPicking(false)}
              />
            ) : (
              <button class="btn btn-secondary btn-small" onClick={() => setPicking(true)}>
                Add folder
              </button>
            )}
          </div>
          {status && (
            <p role="status" class={status === 'Saved.' ? 'muted' : 'error-text'}>
              {status}
            </p>
          )}
          <button class="btn" disabled={busy || !dirty} onClick={() => void save()}>
            Save
          </button>
        </div>
      )}

      <h2>Drive folders</h2>
      <div class="card">
        <button class="btn btn-secondary" disabled={folders.busy} onClick={() => void refreshFolders()}>
          {folders.busy ? 'Refreshing…' : 'Refresh folder list'}
        </button>
        {refreshed && !folders.busy && (
          <p class={folders.error ? 'error-text' : 'muted'}>{folders.error ?? `Loaded ${folders.folders?.length ?? 0} folders.`}</p>
        )}
      </div>

      <h2>Theme</h2>
      <div class="card" role="radiogroup" aria-label="Theme" style={{ display: 'flex', gap: 8 }}>
        {(['system', 'light', 'dark'] as const).map((p) => (
          <button
            key={p}
            role="radio"
            aria-checked={pref === p}
            class={pref === p ? 'btn' : 'btn btn-secondary'}
            onClick={() => setPref(p)}
            style={{ textTransform: 'capitalize' }}
          >
            {p}
          </button>
        ))}
      </div>

      <h2>Account</h2>
      <div class="card">
        <p>
          Signed in as <strong>{email}</strong>
        </p>
        <button class="btn btn-secondary" onClick={() => void logout()}>
          Sign out
        </button>
      </div>
    </main>
  );
}
```

```tsx
    storeOpen
      .then(() => queue.start())
      .catch((e) => console.error('open store', e));
  }, []);

  useEffect(() => {
    if (!email) return;
    storeOpen
      .then(() => store.findInProgress())
      .then((s) => setResume(s))
      .catch((e) => console.error('find in-progress scan', e));
    sync.start();
    return () => {
      sync.stop();
      sync.reset();
    };
  }, [email]);

  function signedOut() {
    setEmail(null);
    setRoute({ kind: 'inbox' });
  }

  async function signInAgain() {
    // The session's Drive access is gone; a fresh login restores it and
    // releases the documents waiting for it.
    await api.logout().catch(() => {});
    signedOut();
  }

  if (!loaded) return <main class="auth-screen">Loading…</main>;
  if (!email) return <LoginScreen onLoggedIn={setEmail} />;

  if (resume && route.kind === 'inbox') {
    return (
      <ResumePrompt
        scan={resume}
        onResume={() => { setResume(null); setRoute({ kind: 'scanner', resumeScanId: resume.id }); }}
        onDiscard={async () => { await store.delete(resume.id); setResume(null); }}
      />
    );
  }

  switch (route.kind) {
    case 'inbox':
      return <InboxScreen
        sync={sync}
        onScan={() => setRoute({ kind: 'scanner' })}
        onSavedScans={() => setRoute({ kind: 'saved' })}
        onSettings={() => setRoute({ kind: 'settings' })}
        onSignInAgain={() => void signInAgain()}
      />;
    case 'settings':
      return <SettingsScreen email={email} onBack={() => setRoute({ kind: 'inbox' })} onLoggedOut={signedOut} />;
    case 'scanner':
      return <ScannerScreen
        store={store}
        queue={queue}
        {...(route.resumeScanId !== undefined ? { resumeScanId: route.resumeScanId } : {})}
        onBack={() => setRoute({ kind: 'inbox' })}
        onDone={() => setRoute({ kind: 'saved' })}
      />;
    case 'saved':
      return <SavedScansScreen
        store={store}
        queue={queue}
        onBack={() => setRoute({ kind: 'inbox' })}
        onNewScan={() => setRoute({ kind: 'scanner' })}
        onView={(scanId) => setRoute({ kind: 'viewer', scanId })}
      />;
    case 'viewer':
      return <ScanViewerScreen
        store={store}
        queue={queue}
        scanId={route.scanId}
        onBack={() => setRoute({ kind: 'saved' })}
      />;
  }
}
```
